# Default Exclusions

Synapse ignores non-source directories, compiled files, packages, and binary assets during indexing.

---

## Excluded Directories

The following directories are skipped wherever they appear in the repository tree:

| Directory | Category |
|---|---|
| `.git` | Version control internal data |
| `.synapse` | Synapse persistent index storage |
| `.venv`, `venv`, `env`, `.env` | Python virtual environments |
| `node_modules` | Node.js / JavaScript package dependencies |
| `__pycache__` | Python bytecode cache |
| `.pytest_cache`, `.mypy_cache`, `.tox`, `.nox`, `.hypothesis` | Testing and typechecking caches |
| `build`, `dist`, `.eggs`, `*.egg-info` | Package build artifacts |
| `.cache`, `htmlcov`, `coverage`, `.coverage` | System caches and test coverage reports |

---

## Excluded File Patterns

The following file patterns are skipped regardless of location:

| Pattern (Regex) | Description |
|---|---|
| `\.min\.(js\|css)$` | Minified script and stylesheet bundles |
| `\.bundle\.(js\|css)$` | Bundled distribution files |
| `\.map$` | Source map files |
| `\.pyc$`, `\.pyo$` | Compiled Python bytecode |
| `\.so$`, `\.dll$`, `\.dylib$` | Dynamic shared libraries |
| `\.exe$`, `\.o$`, `\.a$` | Executables and object files |
| `\.class$`, `\.jar$`, `\.war$` | Compiled Java classes and archives |
| `\.zip$`, `\.tar\.gz$`, `\.whl$`, `\.egg$` | Compressed archives and distribution wheels |
| `\.png$`, `\.jpg$`, `\.jpeg$`, `\.gif$`, `\.ico$`, `\.svg$`, `\.pdf$` | Images, icons, and binary media |
| `\.lock$` | Package manager lockfiles |
| `^synapse_export\.` | Export files generated by Synapse |
