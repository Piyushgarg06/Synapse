# Symbols and Identifiers

Every function, method, class, and interface extracted by Synapse receives a stable identifier derived from its path, scope, kind, and definition sequence.

---

## Symbol Kinds

Synapse classifies AST nodes into four discrete symbol kinds:

- **`class`**: Object-oriented class declarations in Python, JavaScript, and TypeScript.
- **`interface`**: Interface declarations in TypeScript.
- **`function`**: Top-level function declarations or exported function expressions.
- **`method`**: Functions defined within the lexical scope of a class.

---

## Qualified Names

A qualified name reflects the enclosing lexical scope within a file:

| Code Entity | File | Qualified Name |
|---|---|---|
| `class UserService:` | `backend/services/user_service.py` | `UserService` |
| `def get_user(self):` in `UserService` | `backend/services/user_service.py` | `UserService.get_user` |
| `export function formatName():` | `frontend/utils/formatter.js` | `formatName` |
| `export interface User` | `frontend/types.ts` | `User` |

---

## Identifier Construction

Symbol identifiers are deterministic 16-character hexadecimal strings generated by taking the SHA-256 hash of a structured string:

```python
hash_input = f"{file_path}:{qualified_name}:{kind}:{ordinal}"
symbol_id = hashlib.sha256(hash_input.encode("utf-8")).hexdigest()[:16]
```

### Determinism Rules
- **No random UUIDs**: Identifiers remain identical across rebuilds and across machines as long as the symbol definition has not moved.
- **Forward slashes**: `file_path` is normalized to forward slashes across all operating systems.

---

## Handling Duplicate Names (Ordinal)

Some languages permit multiple functions with identical names in the same file (for example, conditional version branches or TypeScript function overloads):

```python
if sys.platform == "win32":
    def get_temp_dir(): return "C:\\Temp"
else:
    def get_temp_dir(): return "/tmp"
```

When Synapse encounters a symbol with an existing `(file_path, qualified_name, kind)` combination in the same file, it increments an integer `ordinal`:

- First definition: `ordinal = 0`
- Second definition: `ordinal = 1`

The SQLite schema enforces uniqueness across these dimensions:

```sql
UNIQUE(file_path, qualified_name, kind, ordinal)
```

This prevents duplicate key collisions while preserving both declarations in the index.

---

## Source Coordinates

Each symbol record stores its physical coordinates:

- `start_line` and `end_line` (1-based line numbers).
- `start_column` and `end_column` (0-based column offsets).
- `start_byte` and `end_byte` (0-based byte offsets).

Coordinates enable retrieval commands such as `synapse context` to extract accurate code snippets from disk.
